# GitHub Issue Templates for ToyEngine

This directory contains issue templates for the ToyEngine project that correspond to the phases and milestones outlined in the project documentation.

## Template Categories

### 1. Phase Completion Issues
Templates for tracking the completion of major development phases.

### 2. Feature Implementation Issues
Templates for implementing specific features within each phase.

### 3. Bug Fix Issues
Templates for addressing bugs and issues found during development.

### 4. Documentation Issues
Templates for documentation tasks and improvements.

## Usage

When creating issues for the ToyEngine project:

1. Select the appropriate template based on the type of work
2. Fill in all required fields
3. Assign to the appropriate milestone
4. Add relevant labels for categorization
5. Link to related issues or pull requests

## Milestone Mapping

Each issue should be assigned to the appropriate milestone based on the phase it belongs to:

- **Milestone 1**: Foundation Infrastructure (Completed)
- **Milestone 2**: Core Rendering Pipeline (Completed)
- **Milestone 3**: Asset Management System (Partially Complete)
- **Milestone 4**: Scene Management (In Progress)
- **Milestone 5**: Editor Integration (In Progress)
- **Milestone 6**: Advanced Rendering Features (In Progress)
- **Milestone 7**: Platform Expansion (Planned)
- **Milestone 8**: Performance and Polish (Planned)
- **Milestone 9**: Advanced Features and Extensibility (Planned)
- **Milestone 10**: Production Readiness (Planned)
